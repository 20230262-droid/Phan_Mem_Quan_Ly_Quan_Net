
# 1. GIỚI THIỆU ĐỀ TÀI

Mô tả hệ thống:

* Đây là module AI tích hợp vào phần mềm quản lý quán net theo mô hình client-server.
* Hệ thống hỗ trợ:

  * tự động trả lời khách hàng
  * hỗ trợ quản lý quán net
  * xử lý đặt món bằng AI
  * phân tích dữ liệu hoạt động quán net
  * hiển thị báo cáo AI

Mô hình tổng quát:

Client → Server → AI Module → AI API → Server → Client

Giải thích vai trò:

* Client gửi yêu cầu
* Server quản lý dữ liệu và logic chính
* AI module xử lý thông minh
* AI API thực hiện NLP và tạo phản hồi

Công nghệ sử dụng:

* Python
* PyQt6
* urllib.request
* threading
* json
* re (regex)
* HTTP REST API
* Groq API (OpenAI-compatible)

```python
_format_session_context()

```

Giải thích:

* AI biết menu quán
* AI biết số dư khách
* AI nhớ lịch sử chat
* AI trả lời theo ngữ cảnh

Khái niệm:

* Context-aware AI
* Prompt Engineering

## GIAI ĐOẠN 8 — XÂY DỰNG AI ĐẶT MÓN

Mô tả:
Ban đầu AI chỉ chat.
Sau đó nâng cấp thêm:

* phát hiện yêu cầu đặt món
* parse dữ liệu
* gửi server xử lý

Phân tích:

```python
_looks_like_order_request()
```

Giải thích:

* dùng regex phát hiện yêu cầu đặt món

Ví dụ:

* “2 trà sữa”
* “cho tôi 1 mì”
* “mua 2 nước”

Sau đó:

```python
_extract_order_items()
```

AI trả JSON:

```json
{
  "items":[
    {"id":1,"qty":2}
  ]
}
```

Parse:

```python
json.loads()
```

Gửi server:

```python
ORDER_SUBMIT:{...}
```

Giải thích:

* AI xử lý ngôn ngữ tự nhiên
* server xử lý nghiệp vụ thật

Khái niệm:

* rule-based + AI hybrid
* NLP
* structured data extraction

## GIAI ĐOẠN 9 — TỐI ƯU HIỆU NĂNG BẰNG ĐA LUỒNG

Mô tả:
Ban đầu gọi AI trực tiếp làm lag giao diện.

Giải pháp:

```python
threading.Thread(target=worker)
```

Giải thích:

* AI chạy ở luồng phụ
* tránh block GUI

Sau đó:

```python
reply_ready.emit(...)
```

và:

```python
reply_ready.connect(...)
```

Giải thích:

* signal-slot mechanism
* thread phụ không thao tác GUI trực tiếp
* gửi dữ liệu an toàn về main thread

Khái niệm:

* Multi-threading
* Event-driven architecture
